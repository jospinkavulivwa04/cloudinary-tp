# Catalogue de Produits - TP Cloud Computing

## Présentation du projet
Ce mini-projet consiste en un catalogue de produits e-commerce responsive et interactif, développé dans le cadre du cours de Cloud Computing. Le site présente une sélection d'articles high-tech avec des descriptions détaillées via des fenêtres modales dynamiques.

## Technologies utilisées
* **HTML5 / CSS3** (avec des styles personnalisés et des effets de design)
* **Bootstrap 5** (pour la grille responsive et les composants d'interface)
* **JavaScript (Vanilla)** (pour la gestion dynamique de la modale de détails)
* **Cloudinary** (pour l'hébergement distant et l'optimisation des images via des URL HTTPS)

## Utilisation de Cloudinary
Les images des produits ne sont pas stockées localement dans le dossier du projet, mais sont hébergées et servies de manière sécurisée via le cloud **Cloudinary**. Leurs liens URL directs sont intégrés dans les balises de la page web.

## Instructions pour exécuter le projet localement
1. Clonez ce dépôt sur votre machine ou téléchargez-le sous format ZIP
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne
