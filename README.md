# Catalogue de Produits - TP Cloud Computing

## Présentation du projet
Ce mini-projet consiste en un catalogue de produits e-commerce responsive et interactif, développé dans le cadre du cours de Cloud Computing[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span). Le site présente une sélection d'articles high-tech avec des descriptions détaillées via des fenêtres modales dynamiques.

## Technologies utilisées
* **HTML5 / CSS3** (avec des styles personnalisés et des effets de design)[span_2](start_span)[span_2](end_span)
* **Bootstrap 5** (pour la grille responsive et les composants d'interface)[span_3](start_span)[span_3](end_span)
* **JavaScript (Vanilla)** (pour la gestion dynamique de la modale de détails)[span_4](start_span)[span_4](end_span)
* **Cloudinary** (pour l'hébergement distant et l'optimisation des images via des URL HTTPS)[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span)

## Utilisation de Cloudinary
Les images des produits ne sont pas stockées localement dans le dossier du projet, mais sont hébergées et servies de manière sécurisée via le cloud **Cloudinary**[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span). Leurs liens URL directs sont intégrés dans les balises de la page web.

## Instructions pour exécuter le projet localement
1. Clonez ce dépôt sur votre machine ou téléchargez-le sous format ZIP[span_9](start_span)[span_9](end_span).
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne[span_10](start_span)[span_10](end_span).
